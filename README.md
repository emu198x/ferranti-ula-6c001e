# ferranti-ula-6c001e

The Ferranti 6C001E, the ZX Spectrum 16K and 48K's ULA.

| Crate | Registry |
|---|---|
| [`emu198x-ferranti-ula-6c001e`](crates/emu198x-ferranti-ula-6c001e) | [crates.io](https://crates.io/crates/emu198x-ferranti-ula-6c001e) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the 16K, 48K and Spectrum+.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
